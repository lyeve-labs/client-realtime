# Security

## Reporting a vulnerability

If you find a security vulnerability in `@lyeve-labs/client-realtime`, **do not**
open a public issue. Send the details to **security@lyeve.com** instead. We'll
acknowledge within 48 hours and aim to resolve within 7 days.

## Supported versions

| Version  | Supported          |
| -------- | ------------------ |
| latest   | :white_check_mark: |
| < latest | :x:                |

Only the latest published version receives security patches.

## Disclosure

We follow coordinated disclosure. After a fix is released, you'll be credited
in the release notes if you wish. Please give us a reasonable window before
disclosing publicly.
